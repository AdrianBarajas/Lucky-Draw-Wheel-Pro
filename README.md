# Lucky-Draw-Wheel-Pro

## Publish with GitHub Pages

The site is deployed automatically from the `main` branch by the workflow in
`.github/workflows/deploy.yml`.

Before the first deployment, open **Settings > Pages** in the repository and
set **Source** to **GitHub Actions**. Then push a commit to `main`, or run
**Deploy to GitHub Pages** from the **Actions** tab.

The deployed site URL is shown in the workflow run and in the
`github-pages` environment.
