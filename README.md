# Lucky-Draw-Wheel-Pro

## Publish with GitHub Pages

The site is deployed automatically from the `main` branch by the workflow in
`.github/workflows/deploy.yml`. The workflow also enables GitHub Pages for the
repository on its first run.

Push a commit to `main`, or run **Deploy to GitHub Pages** from the
**Actions** tab. If automatic enablement is not permitted, open
**Settings > Pages** and set **Source** to **GitHub Actions**.

The deployed site URL is shown in the workflow run and in the
`github-pages` environment.
